# Diadem

Консольный DLNA (UPnP AV) медиа-сервер: запускается из папки с медиафайлами и делает её содержимое доступным для плееров в локальной сети, прежде всего VLC на телевизоре в гостиной.

## Language

**Diadem**:
Само приложение; также Friendly Name сервера по умолчанию.
_Avoid_: сервер, dlna-server (когда имеется в виду продукт целиком)

**Library**:
Корневая папка, содержимое которой раздаётся клиентам. Задаётся папкой запуска или аргументом пути.
_Avoid_: share, коллекция, медиатека

**Content Directory**:
Сервис UPnP, по которому клиент просматривает Library (browse). Протокольный термин стандарта.
_Avoid_: плейлист, каталог (в протокольном смысле)

**Container**:
Элемент Content Directory, зеркалирующий папку на диске; содержит вложенные Containers и Items.
_Avoid_: folder, директория (когда говорим о том, что видит клиент)

**Item**:
Элемент Content Directory, зеркалирующий один медиафайл (видео, аудио или фото).
_Avoid_: файл, трек, ролик (когда говорим о том, что видит клиент)

**Media Kind**:
Классификация Item по типу содержимого: Video, Audio или Photo. Определяет иконку в TUI и UPnP-класс в Content Directory.
_Avoid_: формат, тип файла, категория

**Client**:
Плеер или устройство, которое находит Diadem по SSDP и тянет медиа само (pull); например, VLC на телевизоре.
_Avoid_: renderer, player, телевизор (как синоним клиента в целом)

**Friendly Name**:
Имя сервера, которое видит Client в списке источников. По умолчанию — Diadem.
_Avoid_: имя хоста, заголовок
