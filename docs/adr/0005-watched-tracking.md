# Отслеживание просмотренного: порог по отданным байтам, состояние в Library

Боль: в папке много видео, не вспомнить, на чём остановился — особенно в сериале
или через неделю. Протокол факт просмотра не передаёт: VLC — pull-клиент без
AVTransport и без авторизации, серверу известно только то, что уходит по HTTP.
Поэтому Watched (CONTEXT.md) выводится из трафика раздачи: суммарно отданные
Client'ам байты Item'а достигли 30% его размера (порог — константа
`WatchedPercent`), либо Item отмечен вручную (`w` в TUI). Считается любой Client,
счётчик — один на Item. Метка только ставится автоматически: повторный просмотр её
не снимает, снимает только ручной toggle.

Состояние (Watch State) живёт в памяти, зеркало — `.diadem/watched.json` в корне
Library, всегда перезаписывается целиком (temp + rename). Ключ записи — путь +
размер: переименование или замена файла честно сбрасывает отметку. Запись — по
трём триггерам: изменение состояния (debounce ~2 с), свежий снапшот Library
(чистка + флеш), graceful shutdown. Чистка строгая: запись умирает, только если
родительский Container есть в новом снапшоте, а Item с тем же путём и размером —
нет; пропавшая целиком папка (внешний диск, флэк маунта) свои записи сохраняет.

## Considered Options

- Playhead ≥ 90% длительности («досмотрел до конца») — точнее по словам, но
  требует сессионной логики по последовательности Range-запросов, ломается о
  moov-атом в конце MP4 (VLC читает хвост файла при открытии — наивный максимум
  смещения помечает всё мгновенно) и даёт ложный негатив при выключении на титрах
- Суммарно отданные байты ≥ 30% **(выбрано)** — устойчиво к перемоткам,
  переподключениям и клиентам без Range; механизм — простой счётчик
- Скрывать просмотренное из Browse — без авторизации необратимо лишает доступа к
  файлу; отвергнуто вовсе, даже как флаг
- Resume-позиция «досмотреть с минуты» — DLNA pull-клиенту её не передать, была
  бы видна только в TUI; v1 хранит только флаг

## Consequences

- Эпизод, брошенный на 35%, станет Watched, а перемотки в первых ~25% могут
  набрать порог без «настоящего» просмотра — принятая цена за устойчивость
  механизма; порог поправим константой после ручной проверки на телевизоре
- Маркер ` · ✓` — суффикс Display Title: префикс сломал бы сортировку серий,
  ради которой Display Title и существует; клиент видит метку после повторного
  захода в Container (GENA нет, `systemUpdateID` не меняется)
- Два одновременно запущенных Diadem на одной Library затирают файл состояния
  друг друга (last-writer-wins) — принято для домашнего сценария
- Первый запуск создаёт `.diadem/watched.json`; битый файл — старт с пустым
  состоянием, полный сброс — удалить файл при выключенном сервере
