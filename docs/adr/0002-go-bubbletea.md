# Go + Bubble Tea в качестве стека

TUI — центр продукта («ренессанс консольных интерфейсов»), поэтому фреймворк выбирался по эстетике и зрелости: экосистема charmbracelet (Bubble Tea, Lipgloss) задаёт тот самый узнаваемый стиль (gh, glow, gum) и отдаёт статический бинарник. Go уже установлен в рабочем окружении, а главный референс по DLNA-совместимости — `anacrolix/dms` — написан на Go, что упрощает перенос тонкостей протокола. Альтернативы: Rust + ratatui (тулчейн не установлен, зрелых серверных DLNA-библиотек нет), Python + Textual (не single-binary), Node + Ink (слабее как TUI-фреймворк).
